# Backend — Agent Instructions (SCRI Oncology Copilot)

This is the FastAPI backend service for **Sarah Cannon Research Institute (SCRI) Oncology Copilot**. Read [../AGENTS.md](../AGENTS.md) first — universal building rules and clinical domain guidelines live there. This file adds backend-specific conventions.

---

## 1. Stack

- **Runtime:** Python 3.12+
- **API Framework:** FastAPI + Uvicorn
- **Settings & Validation:** Pydantic v2 + pydantic-settings
- **Agent Orchestration:** PydanticAI (typed agent boundaries, outputs, and dependencies)
- **Outbound HTTP:** `httpx`
- **Testing:** `pytest` + `pytest-asyncio`
- **Database Access:** Supabase Python client + SQLAlchemy 2.0 (async engine)
- **Migrations:** Alembic (direct session connection string for DDL)
- **Embeddings & LLM:** OpenAI SDK (`text-embedding-3-small` + `gpt-4o`)
- **Retrieval:** Supabase `pgvector` for semantic search + Postgres full-text search for exact medical keyword retrieval. Fused via Reciprocal Rank Fusion (RRF).
- **Logging:** `structlog`
- **Package Management:** `uv`

---

## 2. Dependency Policy

See universal policy in [../AGENTS.md](../AGENTS.md). Backend-specific rules:

- **Prefer Standard Library:** `pathlib`, `datetime`, `uuid`, `enum`, `dataclasses`, `asyncio`, `collections`, `itertools`, `json`, `urllib`.
- **Prohibited Without Explicit Justification:** `python-dateutil`, `toolz`, `funcy`, `more-itertools`, small JSON/string micro-libs, or third-party "ergonomic" wrappers over declared SDKs.
- **Dev Dependencies:** Keep test and lint tooling standard and low-footprint (`pytest`, `pytest-asyncio`, `ruff`, `httpx`).

## 4. Code Style & Architectural Patterns

- **Type Hints:** Use type hints on all public functions, route handlers, and module interfaces. Avoid annotating every trivial local variable.
- **Async by Default:** All FastAPI route handlers, database operations, and HTTP network requests must use `async def` and non-blocking I/O.
- **Boundary Validation Only:** Validate input schemas at HTTP boundaries with Pydantic models. Trust internal calls between internal modules.
- **Explain "Why", Not "What":** Comments must explain clinical or architectural rationale (e.g. why an exclusion criterion cannot be null, or why RRF smoothing constant is 60). Never write comments that merely rephrase the syntax.

---

## 5. Configuration & Secrets

- `app.config.settings` is the **single source of truth**. Import `settings` where needed; never call `os.getenv` or `load_dotenv` in application modules.
- **Fail Fast:** If an essential environment variable (`SUPABASE_URL`, `DATABASE_URL`, `OPENAI_API_KEY`) is missing on startup, crash immediately with an informative error message.

---

## 6. Database Migrations

- Alembic is the source of truth for schema changes. Never modify production tables manually in the Supabase dashboard.
- SQLAlchemy models describe normal tables and columns. Autogenerated migrations must be carefully reviewed before applying.
- Supabase/Postgres-specific features belong in explicit migration operations: `create extension if not exists vector`, generated `tsvector` columns, HNSW/GIN indexes. **RLS policies are planned for a future numbered migration (Phase 4 / pre-deployment) — they are NOT in `0001`.**
- Alembic must use the direct/session database connection (port 5432), not the transaction pooler URL (port 6543).
- Run migrations from `backend/` with `uv run python -m alembic upgrade head` (use the `-m` module form on Windows to avoid the `uv trampoline` path error).

---

## 7. Testing & Grounding Verification

- **Fast Unit Tests:** The unit test suite (`uv run python -m pytest -m "not integration"`) must stay green and hit no external network or live database.
- **Integration Tests:** Integration tests requiring live OpenAI or Supabase credentials must use `@pytest.mark.integration` (`uv run python -m pytest -m integration`).
- **Mandatory Coverage:** Section-aware chunking, hybrid retrieval fusion (RRF), citation validation, and protocol silence negative refusal must have explicit tests.
- **Windows Tooling Note:** Always invoke CLI scripts via `uv run python -m <module>` (e.g. `python -m pytest`, `python -m alembic`) rather than bare entrypoints to ensure cross-platform path resolution.

---

## 8. Anti-Patterns (Rejected)

- `os.getenv` or `load_dotenv` called outside `app/config.py`.
- Wrapping FastAPI responses in custom redundant JSON envelope classes.
- Over-catching `Exception` just to log and re-raise.
- Shared state through global variables instead of FastAPI dependency injection.
- Silent fallbacks that hide missing clinical criteria or missing credentials.
- Fabricating criteria when a protocol is silent instead of declaring that the document does not state the requirement.
